# Edge AI Smart Road Damage Detection

A computer vision-based road damage detection system designed to identify potholes and cracks in road images using YOLO.

## Project Overview

Road damage such as potholes and cracks can affect road safety and maintenance. This project explores automated detection using deep learning and computer vision techniques.

## Technologies Used

- Python
- YOLO (Ultralytics)
- PyTorch
- Google Colab
- Roboflow
- React.js (dashboard development)

## Key Components

- Road image dataset preparation and preprocessing
- YOLO-based object detection for potholes and cracks
- Model training and performance evaluation
- Detection result visualisation through a React dashboard

## Model Performance

- Evaluation metric: mAP@50
- Recorded mAP@50: 0.88 at epoch 7 of 15 during a training run

## Project Status

Model development and dashboard integration are in progress.
